# bunkim

**bunkim** is a fast, responsive student attendance cushion & headroom calculator built with **React 19**, **TypeScript**, **Tailwind CSS**, and **GSAP 3**.

---

## Features

- **Instant Attendance Headroom**: Know exactly how many classes you can skip while staying above your required threshold, or how many consecutive classes you must attend to recover.
- **Neo-Tactile Aesthetic**: Solid borders, clean shadows, and zero-gradient design in both Light & Dark modes.
- **GSAP 3 Micro-Interactions**: Smooth choreography on entrance, spring number bounce, and celebratory confetti.
- **What-If Simulator**: Real-time projection for attending or missing the next class.
- **Subject-Wise Roster**: Track separate criteria for theory courses and labs with an aggregate percentage.
- **10 Regional Languages**: Localized with auto-detection for English, Hindi, Telugu, Tamil, Kannada, Malayalam, Bengali, Marathi, Spanish, and German.
- **100% Client-Side & Private**: No analytics, trackers, or server storage.

---

## Tech Stack

- **Framework**: React 19 + TypeScript (Vite)
- **Styling**: Tailwind CSS v4
- **Animation**: GSAP 3 + `@gsap/react`
- **Icons**: `lucide-react`
- **Typography**: *Space Grotesk*, *Plus Jakarta Sans*, *JetBrains Mono*

---

## Local Development

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build standalone production bundle
npm run build
```
